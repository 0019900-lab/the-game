# LAWLESS — The World Forgot Its Laws

لعبة ألغاز فيزياء 2D. أنت لا تحرّك الأشياء، أنت تغيّر القانون الذي يحرّكها.
هذه النسخة: **المرحلة 1 (THE AWAKENING) — 5 غرف**، قانون **GRAVITY**، تعمل كـ PWA.

## تشغيل محلي
```
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000` (الـ Service Worker لا يعمل من `file://`).

## الرفع على GitHub Pages (مجاني)
1. أنشئ مستودعًا جديدًا على GitHub (مثلًا `lawless`).
2. ارفع **محتويات** هذا المجلد في جذر المستودع (وليس المجلد نفسه): `index.html` و`game.js` و`sim.js` و`rooms.js` و`audio.js` و`sw.js` و`manifest.json` ومجلد `icons`.
3. من **Settings ← Pages**: اختر Branch = `main` و Folder = `/ (root)` ثم Save.
4. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/lawless/`
5. افتحه على الموبايل: Android (Chrome) ← قائمة ⋮ ← «تثبيت التطبيق». iPhone (Safari) ← مشاركة ← «إضافة إلى الشاشة الرئيسية».

عند أي تحديث: غيّر `VERSION` في `sw.js` (مثلًا `lawless-v2`) حتى يتحدّث التطبيق عند المستخدمين.

## تحقق من الألغاز
```
node validate.js
```
يتأكد أن كل غرفة لها حل، ويطبع الحل الأمثل (المستخدم كقيمة `par` للنجوم).

## إضافة غرفة جديدة
أضف عنصرًا في `rooms.js`. الرموز: `#` جدار · `H` عنصر محصّن · `E` بوابة (في الجدار العلوي) · `B` كتلة · `P` مفتاح ضغط · `.` فراغ.
شغّل `node validate.js` وانسخ الحل الأمثل إلى `par`.

## الخطوات التالية
- **APK**: ارفع رابط الـ PWA على https://www.pwabuilder.com ثم Android، أو استخدم Capacitor.
- **EXE**: Electron أو Tauri يلفّان نفس الملفات. (أو ثبّت الـ PWA من Edge/Chrome على ويندوز.)
- **iOS في المتاجر** يحتاج حساب مطوّر مدفوع؛ الـ PWA تعمل مجانًا عبر «إضافة إلى الشاشة الرئيسية».

## التحكم
- موبايل: اضغط الكتلة ← اختر اتجاهًا (سهم / أزرار الاتجاه / اسحب من الكتلة) ← SIMULATE.
- كمبيوتر: ماوس أو الأسهم/WASD · Space = تشغيل · Z تراجع · Y إعادة · R إعادة الغرفة · Tab تبديل الكتلة · Esc إيقاف.
